# Free3Books

## Deskripsi

Free3Books adalah situs web sederhana yang menyediakan koleksi buku elektronik (ebook) gratis yang dapat diunduh oleh pengguna. Proyek ini dibangun dengan HTML, CSS, dan JavaScript, serta menampilkan daftar buku dengan gambar mini, judul, dan tautan unduhan.

-----

## Fitur

  * **Katalog Buku**: Menampilkan daftar buku yang tersedia dengan gambar sampul dan judul.
  * **Pencarian Mudah**: Pengguna dapat mencari buku berdasarkan judul.
  * **Unduh Gratis**: Setiap buku dapat diunduh dalam format PDF.

-----

## Cara Menggunakan

1.  **Buka `index.html`**: Buka file `index.html` di browser web Anda.
2.  **Jelajahi atau Cari**: Jelajahi daftar buku yang tersedia atau gunakan bilah pencarian untuk menemukan buku tertentu.
3.  **Unduh**: Klik tombol "Unduh" di bawah buku yang Anda inginkan untuk mengunduh file PDF-nya.

-----
